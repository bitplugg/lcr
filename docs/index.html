LCR

Lavender Custom Recovery — TWRP-based recovery for the
Xiaomi Redmi Note 7 / Note 7S (lavender / lavenderin)

Download latest GitHub Wiki

Features

Custom design

LCR splash screen, brand theme and terminal ASCII banner, tuned for the 1080×2340 display.

LCR toolset

Built-in scripts: Magisk install, EDL, EFS backup, ARB check, verity/SELinux toggles, wipe helpers and more.

Magisk bundled

The latest Magisk package ships inside the ramdisk under /system/etc/lcr.

Decryption

Qualcomm decrypt services (qseecomd / keymaster / gatekeeper) wired into init.recovery.

Install

# Reboot to bootloader
adb reboot bootloader

# Flash the recovery image
fastboot flash recovery recovery-LCR-lavender.img

# If your device uses AVB, disable verification
fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img

fastboot reboot recovery

Flash at your own risk. Unlocking the bootloader wipes your data. Always keep a backup.
